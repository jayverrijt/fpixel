🔑 Inloggen op FPixel

Nog geen wachtwoord ingesteld of vergeten? Reset je wachtwoord met een in-game code of gebruik in Minecraft /webpass <wachtwoord>.

Hoe wachtwoord resetten werkt: Vul je Minecraft naam in en klik op Stuur Code. Je ontvangt direct in je Minecraft chat een 6-cijferige verificatiecode. Vul die hieronder in om een nieuw wachtwoord in te stellen.

💡 Zorg dat je online bent op mc.fpixel.nl om de code in je chat te ontvangen.
