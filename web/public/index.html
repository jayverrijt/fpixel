📖 Hoe Join Je FPixel?

Instructies voor Java Edition en Bedrock Edition (Console, Mobile & Windows)

☕ Java Edition

PC / Mac / Linux

  1. Start Minecraft (versie 1.21.x / 26.3).
  2. Klik op Multiplayer → Server Toevoegen.
  3. Server Adres: mc.fpixel.nl
  4. Klik op Gereed en verbind direct!
🎮 Bedrock Edition

Mobile / Windows / Consoles

  1. Start Minecraft op je telefoon, console of Windows.
  2. Ga naar Spelen → Servers → Server Toevoegen.
  3. Server Naam: FPixel Network
  4. Server Adres: mc.fpixel.nl
  5. Poort: 19132 (Standaard Bedrock poort).
